# Welcome to ClipTova

**Every long video has a short story.**

ClipTova is an AI-powered video repurposing platform that transforms long-form videos into engaging short-form clips.

## Our Vision

Discover the best moments. Create engaging clips. Share great content.

## Supported Content

- Podcasts and interviews
- Gaming streams
- Educational videos

## Technology

- React + TypeScript
- Java 17 + Spring Boot
- PostgreSQL
- FFmpeg
- Whisper AI

Let's build ClipTova!
